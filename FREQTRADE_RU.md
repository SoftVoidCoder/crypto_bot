# RegimeFlow — запуск и проверка

Это основной вариант бота на Freqtrade 2026.9 с официальным FreqUI. Он работает с
фьючерсами Bybit USDT Perpetual: `BTC/USDT`, `ADA/USDT`, `DOGE/USDT`.

## Что уже включено

- тёмная веб-панель, графики, сделки, прибыль, win rate и журналы;
- лимитные входы/выходы, рыночный аварийный стоп на бирже;
- RSI, MACD, ADX, ATR, EMA, Bollinger Bands, объём и стакан;
- long/short, определение тренда и блокировка аномальной волатильности;
- 1× плечо, isolated margin, не более трёх сделок и 45% капитала суммарно;
- блокировки после стопов, просадки 8% за окно и слабых результатов пары;
- Telegram-уведомления через стандартный модуль Freqtrade;
- dry-run, Bybit Testnet, backtest и отдельно заблокированный mainnet.

## Сейчас: безопасная симуляция

Запуск:

```bash
./scripts/ft_dry.sh
```

Открыть <http://127.0.0.1:8080>. Начальный логин: `gridpilot`, пароль:
`change-me-now`. Поменяйте их через переменные из `.env.freqtrade.example`.

Dry-run использует реальные котировки, но сделки и баланс симулирует локально.
Остановить можно кнопкой Stop в панели или `Ctrl+C` в терминале.

## История и бэктест

```bash
./scripts/ft_download.sh 365
./scripts/ft_backtest.sh --timerange 20251010-20261003 --cache none
```

В текущем контрольном прогоне стратегия убыточна. Это рабочая инфраструктура, но
не готовая прибыльная модель: не переводите её на реальные деньги. Следующий этап —
walk-forward-подбор на train-окнах и проверка на нетронутом out-of-sample периоде.

## Bybit Testnet

Ключи остаются только в `.env.testnet`; скрипт не печатает их:

```bash
./scripts/ft_testnet.sh
```

Для ключа достаточно чтения аккаунта/позиций и торговли деривативами. Вывод средств,
переводы, P2P, Earn, Bybit Pay и публикации не нужны.

## Mainnet

Безопасный просмотр реального баланса запускается отдельно и остаётся остановленным:

```bash
./scripts/ft_mainnet_monitor.sh
```

Панель Mainnet: <http://127.0.0.1:8081>. Автоматическая торговля намеренно имеет
дополнительную блокировку:

```bash
FREQTRADE_REAL_CONFIRM=I_UNDERSTAND_REAL_MONEY ./scripts/ft_mainnet.sh
```

Не запускайте его до положительного out-of-sample теста и нескольких недель Testnet.
Bybit Unified Account для Freqtrade должен быть выделен под бота: ручные сделки в том
же аккаунте могут нарушить учёт позиций.

## Telegram

Скопируйте `.env.freqtrade.example` в `.env.freqtrade`, внесите токен BotFather и
chat ID, затем перед запуском выполните `set -a; source .env.freqtrade; set +a`.
Уведомления включены для входа, исполнения, выхода, ошибок и срабатывания защит.
